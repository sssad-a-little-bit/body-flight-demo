# Body Flight · Flare Studio

Демонстрационный одностраничный сайт на русском языке. Next.js + TypeScript, статический экспорт, без бэкенда, аналитики и серверных отправок. Абстрактная SVG-графика создана для концепции, фотографии студии не используются. Шрифт Manrope хранится локально с лицензией OFL.

## Локальный запуск

```bash
cd /workspace/sites/body-flight
npm ci
npm run dev
```

Открыть http://localhost:3000. Нужен Node.js 20.9 или новее.

```bash
npm test
npm run typecheck
npm run build
```

Готовый статический сайт находится в `out/`. `npm start` не используется для статического экспорта; для локального просмотра сборки можно выполнить `python3 -m http.server 3000 --directory out`.

## Контакты и сообщения

`src/lib/studio.ts` — единственный конфигурационный файл для названия, города, телефона и адреса. От них вычисляются телефонная ссылка, номер WhatsApp и поиск в 2ГИС. Там же находятся направления и функция сборки сообщения. Не меняйте отдельно номер в разметке.

Форма работает только в браузере: направление и необязательное время попадают в параметр `text` ссылки `wa.me`. Сообщение отправляет сам посетитель в WhatsApp. Запись подтверждает студия в переписке. Сайт ничего не сохраняет, автоматически не отправляет и не запрашивает имя или телефон.

Демо закрыто от индексации метатегами `noindex, nofollow` (включая Googlebot) и `robots.txt`. Это не ограничение доступа. Приватность показа обеспечивает доступ Sites.

## Проверки

`npm test` проверяет все три направления, точный номер, тексты, необязательное время, кириллицу, пробелы и специальные символы, телефонную ссылку и URL поиска в 2ГИС. Диалог использует нативный `<dialog>`: браузер ограничивает фокус, закрывает его по Escape; обработчик `close` восстанавливает прокрутку и фокус исходной кнопки. Фокус видим, FAQ управляется клавиатурой через `<details>`, движение отключается при `prefers-reduced-motion`.

В этой среде браузерный инструмент недоступен: интерактивные проверки на 360 px и десктопе, Escape, цикл Tab, возврат фокуса и отсутствие горизонтальной прокрутки требуют ручной проверки. Проверить после запуска:

1. На ширинах 360 и 1440 px пройти от первого экрана к направлениям.
2. У каждого направления нажать «Хочу попробовать», сверить выбранный пункт и ссылку WhatsApp; изменить направление и добавить время.
3. Закрыть окно по Escape, проверить возвращённый фокус; повторить через кнопку закрытия. Tab / Shift+Tab должны оставаться внутри открытого окна.
4. Открыть все вопросы клавиатурой. Проверить контактный телефон и поиск адреса в 2ГИС.
5. Проверить `document.documentElement.scrollWidth === window.innerWidth`, в том числе при открытом диалоге.

## До публичного запуска запросить у владельца

- Подтверждение телефона, адреса, офиса, входа и точки в 2ГИС.
- Цены, расписание, условия и стоимость пробного, порядок подтверждения и отмены записи.
- Возрастные условия, подготовку новичков, рекомендации по одежде и вещам для каждого направления.
- Конкретные снаряды воздушной гимнастики и подтверждённое описание занятий.
- Имена и согласованные сведения о тренерах, фотографии и права на их использование.

После согласования заменить вопросы на подтверждённые условия и отдельно решить, когда снимать noindex и открывать публичный доступ.

## GitHub Pages

Адрес GitHub Pages: https://sssad-a-little-bit.github.io/body-flight-demo/

Workflow `.github/workflows/pages.yml` запускает тесты, собирает статический сайт и публикует его в GitHub Pages при push в `main`. Источник Pages в настройках репозитория — GitHub Actions. Перед сборкой задаётся `NEXT_PUBLIC_BASE_PATH=/body-flight-demo`, чтобы ресурсы правильно загружались из подпапки. Локальный запуск без этой переменной продолжает работать по корневому адресу.

Для GitHub Pages нужен публичный репозиторий (либо поддерживающий приватные Pages тариф). Публикация выполняется GitHub Actions из ветки main. Метатег noindex сохранён.
